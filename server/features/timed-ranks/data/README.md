# English word-frequency lookup

`wordfreq-en.tsv` is an ENABLE dictionary intersection of the English **large**
word list in [wordfreq 3.1.1](https://pypi.org/project/wordfreq/3.1.1/), by
**Robyn Speer**, copyright 2022. Frequencies are Zipf scores, not game statistics.
Words with an absent/zero estimate are omitted so the application can distinguish
missing coverage from observed low frequency. The application uses difficulty
0.5 for missing words.

Generated by `scripts/buildWordFrequency.py`; that script documents the pinned
installation and regeneration command. Output is uppercase, sorted and rounded
to two decimal places. Python is needed only for regeneration, not deployment.
